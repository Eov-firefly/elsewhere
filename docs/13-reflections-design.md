# 观看感受与个人轨迹 — 功能设计草稿

状态：已实现开发版。已确认默认仅本人可见、可以主动公开；语音输入优先，文本框为补充。基于用户提出的「观看中或观看后记录感受、上传平台、长期查看轨迹和收获」需求。

## 用户提出的目标

- 观看中或观看后都能记录，不依赖系统判断是否看完。
- 感受上传到平台保存，长期回看自己把注意力放在了哪里、当时有什么感受。
- 「10 分钟」继续沿用品牌概念，不是必须完成的时长，也不是系统已经验证的观看时长。

## 本轮实现体验

1. 在内容详情页提供轻量入口「这一刻，你有什么感受？」。不弹窗打断，不强制填写，不把写感受作为完成条件。
2. 先展示语音入口，用户主动点击后调用浏览器语音识别，支持普通话和英语；显示转写文字供检查修改。文本框折叠为「编辑转写／改用文字」。可选标注「正在看／暂时看到这里／看完了」与自述感受。观看状态由用户声明；外站点击不能作为完成证明。
3. 输入先留在本地草稿；保存成功后清楚提示已同步到平台。失败时保留草稿和重试入口，不声称保存成功。
4. 同一内容允许多次记录，支持分次观看。重新接触相同内容时不覆盖以前的感受。
5. 「我的足迹」按时间倒序呈现内容、记录日期和原文，支持有限分页；按月回顾可以显示记录次数与涉及主题，不把记录次数当成学习成效。
6. 可编辑和删除自己的记录。删除个人数据时包含相关记录。来源下架后保留用户自己的文字，隐藏受限制的原内容入口；具体内容保留政策需明确。

## 与现有功能的边界

- 「值得／不适合我」是给编辑的选题反馈；感受是用户为自己留下的个人内容。
- 收藏代表以后想看，不等于看过；记录感受不等于完成观看。
- 不设连续打卡、观看时长排名、收获评分或自动生成的「成长结论」。允许只有放松、快乐或审美感受。
- 首版不默认增加公共动态流、点赞或关注，避免引入无限消费入口。

## 已确定的可见范围及实现选择

用户已选择「默认仅自己可见，可主动公开」。本轮以独立分享链接实现主动公开，不增加公共动态流。分享前明确告知链接持有人可看到正文和作者用户名；撤回、编辑或删除立即使旧链接失效。

- 若仅私人：重点是账户归属、同步可靠性、回顾、导出和删除。
- 若允许公开：还需要明确发布同意、作者展示、撤回、举报、审核、限流及他人访问范围；保存私人记录不能隐式公开。
- 现有随机设备 ID 只支持本设备反馈，不能承诺换设备或清除浏览器后还能找回长期记录。长期同步需要可恢复的账户认证；不应把知道一个公开 UUID 当成读取私人记录的权限。

## 技术设计方向（待确认后实现）

- 新增独立的 Reflection 实体，不把长文本塞进 events 或 feedback。关联用户、内容及记录时的修订版本，保存用户正文、声明的观看状态、创建／更新时间及可见性。
- 私人记录接口必须验证账户所有权；公开查询与本人查询分别限定返回字段。
- 时间线使用游标分页，日期按明确的显示时区呈现。统计仅来自用户自己的记录，不推断实际观看分钟数或认知提升。
- 写入提供幂等性与编辑并发检查，避免网络重试生成重复感受或覆盖另一设备的新修改。
- 语音优先以浏览器识别转写实现；浏览器服务可能处理音频，Elsewhere 不接收或保存原始录音。只有确认保存的文字上传平台。不支持语音、拒绝麦克风或识别失败时仍可使用文字。图片、录音文件归档、AI 总结和社交互动后置。
- 可选用户名／密码账号支持跨设备登录；Argon2id 保存密码哈希，登录令牌哈希存库，HttpOnly / SameSite=Strict Cookie 传输会话。浏览精选仍无需登录。没有邮箱收集及密码找回流程，界面明确说明。
- 个人日记可导出、单条删除、删除整个账号；账号删除需再次验证密码。清理设备反馈的旧入口不会误删账号日记，界面提供账号删除入口。

## 验收重点

- 未登录或其他账户不能读取、修改、删除私人感受。
- 长访谈分三次观看可留下三条独立记录。
- 保存失败不丢输入；重试不重复创建；另一设备的新版本不被静默覆盖。
- 用户的公开／私人选择得到明确执行；若有公开分享，撤回后匿名访问立即失效。
- 个人数据删除覆盖感受、相关草稿和共享入口，不能仅清空界面。
- 来源下架不重新泄露受限制原内容；不会把合成测试记录展示为真实用户收获。
